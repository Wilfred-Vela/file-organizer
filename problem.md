# Problem
People who regularly download or create files often end up with cluttered folders containing documents, images, videos, and other file types mixed together. Finding a particular file can become difficult, especially when files are not organized into separate folders. Manually sorting files takes time and can become frustrating.

# Initial requirements
- R1: The program must run from the terminal on the user's computer with one command, and must not require an API key, account, or paid service.
- R2: The user must be able to provide a folder path as a command-line argument.
- R3: The program must scan the files in the selected folder.
- R4: The program must identify files based on their extensions.
- R5: The program must organize files into folders based on their file types.
- R6: The program must create the necessary folders if they do not already exist.
- R7: Files without extensions must be placed in a separate folder.
- R8: The program must display a summary of the files it organized.
- R9: The program must handle invalid folder paths and display a helpful error message.
- R10: The program must not organize files inside subfolders.
